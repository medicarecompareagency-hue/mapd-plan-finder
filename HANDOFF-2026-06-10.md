## Shipped this session (2026-06-10) — don't redo

### 1. PBP periodicity codebook fix (the big one)
`import-pbp.js` / `enrich-ssbci-benefits.js` assumed per-codes 1=yr/2=mo/3=qtr/4=6mo/5=other.
The ACTUAL codebook (verified against `PBP_Benefits_2026_dictionary.xlsx`):
**1=every 3 YEARS, 2=every 2 YEARS, 3=every YEAR, 4=every 6 months, 5=every 3 MONTHS
(quarter), 6=Other/Describe, 7=every MONTH.** Quarterly OTC cards were 3x overstated and
labeled "/mo". Corrected in both scripts + re-derived DB-wide via
`scripts/rederive-otc-food-allowances.js` (502 plans / 10,732 rows). New column:
`foodCardMaxPeriod`.

### 2. Ambulance + PCP copays: min → MAX (Dale's range rule)
Importer stored the PBP range MINIMUM (often a waived $0 — Devoted H9888-1 showed $0
ambulance; truth $405). Fixed in `enrich-plan-copays-from-pbp.js`; re-derived DB-wide via
`scripts/rederive-ambulance-pcp-copay.js` (amb 561 plans, PCP 117). ER had zero min≠max.

### 3. MA-Only reclassification via pbp_mrx (plan-level truth)
`scripts/reclassify-ma-only-from-mrx.js`: `mrx_drug_ben_yn=2` = no Part D → MA_ONLY.
Moved 210 planIds / 49,160 rows out of MAPD (Aetna Eagle, Humana Honor, AARP Patriot…).
Supersedes the landscape-keyed reclassify for catching strays.

### 4. SB PDFs are the source of truth for OTC / Food Card
- New columns: `sbVerifiedOtcPeriod`, `sbVerifiedFoodPeriod` (filed cadence per the SB).
- `extract-sb-benefits.ts` upgrades: stores periods; copay-adjacency penalty (UHC tables
  put "$25 copay" rows inside the OTC window); distinct-amount runner-up fix (float-noise
  ties); **pdftotext -layout fallback when pdf-parse returns <500 chars** — pdf-parse
  silently fails on ALL Humana 2026 SBs (font-type mismatch; they are NOT scans).
- Ran the engine over all 1,376 unique SB docs: 833 plans with SB-verified OTC, 429 food.
- Same-wallet rule: when extracted food amount === OTC amount AND the SB uses expansion
  language ("may also use this money…"), it's ONE card — write OTC only, no food dollars
  (Humana Healthy Options pattern, e.g. H1036-143 = $30/mo all members, food N/A).
- Suppression rule (route `effectiveOtc`): hide PBP OTC ONLY when it's IDENTICAL to the
  chronic-gated wallet amount (double-filed). If PBP files a different amount it's a real
  all-member benefit even if the SB doesn't itemize it (CMS base b13b filings are uniform)
  — e.g. Devoted H9888-1 has all-member $100/qtr OTC + separate chronic $35/mo Food & Home.
- Audit artifact: `sb-otc-food-audit.csv` (repo root, gitignored).

## Rules to preserve (future imports/pulls)

- PBP periodicity codes: 1=3yr, 2=2yr, 3=yr, 4=6mo, **5=quarter**, 6=other, 7=month.
  Always check value labels in the PBP dictionary — column names lie.
- SB PDF text: `pdftotext -layout`, never trust pdf-parse alone (fallback now built in).
- PBP range (min≠max): store the MAX. Min is usually a waived/$0 case.
- Part D truth is plan-level `mrx_drug_ben_yn`, not the contract flag or landscape county rows.
- Plan numbers 800-999 = EGWP. Never import; `cleanup-egwp-800-series.js` if any sneak in.
- Regional PPOs: counties from landscape; drug tiers in `mrx_tier_rstd_*`.
- SB wins over PBP for OTC/food amount + cadence; PBP OTC suppressed only on exact
  amount match with the gated wallet; same-amount + expansion language = one card.
- DB is Neon. CLI scripts use `makePrisma()`. Never `prisma migrate dev`; `prisma db push`
  for additive schema. Never commit `.env`, `.vercel/`, `.cms-import-tmp/`, `node_modules/`.
